# CRIMES AUTO — ช่องทางแจกจ่ายอัปเดต (release channel)

รีโปนี้คือ **ช่องทางที่โปรแกรม CRIMES AUTO บนเครื่องผู้ใช้ใช้ตรวจสอบและดาวน์โหลดอัปเดต**
ไม่ใช่ที่พัฒนาโค้ดแบบปกติ — โค้ดของโปรแกรมทั้งหมดอยู่ *ในแพ็กเกจ zip* ของแต่ละรุ่น
และรุ่นล่าสุดถูกประกาศผ่าน `update-manifest.json`

| ที่ | คืออะไร |
|---|---|
| `update-manifest.json` | ประกาศรุ่นล่าสุด (เวอร์ชัน · URL zip · sha256 · เปิดให้ทุกคนอัปเดตไหม · บันทึกรุ่น) — **โปรแกรมทุกเครื่องอ่านไฟล์นี้** |
| `CRIMES_AUTO_update_vX.Y.Z.zip` | แพ็กเกจของแต่ละรุ่น (โค้ด `app/` + สคริปต์อัปเดต) เก็บไว้ทุกรุ่นเพื่อย้อนดู/ติดตั้งมือได้ |
| `CHANGELOG.md` | บันทึกการเปลี่ยนแปลงทุกรุ่น (สร้างจากประวัติ manifest) |
| `tests/` | ชุดทดสอบทั้งหมด — รันกับแพ็กเกจรุ่นล่าสุดจริง ๆ (ดูหัวข้อทดสอบ) |
| `tools/release.py` | เครื่องมือปล่อยรุ่น: แตกแพ็กเกจ → สร้าง zip+manifest → ตรวจของออนไลน์ |
| `tools/changelog.py` | สร้าง `CHANGELOG.md` ใหม่ทั้งไฟล์จากประวัติ git |
| `tools/hub_gas.js` | สคริปต์ศูนย์กลางรวมตัวเลข (Google Apps Script) — **ไม่ถูกแจกไปกับโปรแกรม** ([คู่มือ](tools/README.md)) |
| `build/` (ไม่ขึ้น git) | ทรีที่แตกจากแพ็กเกจรุ่นล่าสุด ใช้แก้โค้ดและทดสอบก่อนปล่อยรุ่นถัดไป |
| `.github/workflows/tests.yml` | CI รันชุดทดสอบทั้งหมดทุก PR และทุกครั้งที่ push เข้า `main` |

## การอัปเดตทำงานอย่างไร

1. โปรแกรมบนเครื่องผู้ใช้อ่าน `update-manifest.json` จาก URL ในการตั้งค่า (ค่าเริ่มต้นชี้มาที่ `main` ของรีโปนี้)
2. ถ้า `version` ใหม่กว่าที่ติดตั้ง **และผู้ใช้มีสิทธิ์อัปเดต** จะขึ้นแจ้งเตือน "มีรุ่นใหม่" พร้อม `notes`
3. กดอัปเดต → ดาวน์โหลด zip จาก `url` → **ตรวจ sha256 ต้องตรง** → เรียก `Update.ps1` ในแพ็กเกจ
4. `Update.ps1` ปิดโปรแกรม/Chrome ของระบบที่ค้าง, สำรอง `data.db`, แล้ว **วางทับเฉพาะโฟลเดอร์ `app/`**
   (robocopy แบบ merge) โดยไม่แตะ `app/backend/data/` และ `app/backend/uploads/` — บัญชี ประวัติ การตั้งค่า อยู่ครบ
   ไฟล์ที่รุ่นใหม่ไม่มีแล้วจะ *ไม่ถูกลบ* ออกจากเครื่อง (จึงมีไฟล์เก่าค้างได้ เช่น `licensekey.py`)

### รูปแบบ `update-manifest.json`

| ฟิลด์ | ความหมาย |
|---|---|
| `version` | เลขรุ่น `X.Y.Z` — เทียบเป็นตัวเลขทีละส่วน |
| `url` | ที่อยู่ zip (ต้องเป็นไฟล์ในรีโปนี้บน `main`) |
| `sha256` | แฮชของ zip — โปรแกรมปฏิเสธไฟล์ที่แฮชไม่ตรง |
| `open` | `true` = **รุ่นนี้เปิดให้ทุกเครื่องอัปเดตโดยไม่ต้องได้รับสิทธิ์** (ใช้ตอนต้องดึงทุกเครื่องขึ้นรุ่นเดียวกัน เช่น v3.3.0/v3.4.0) · `false` = ตามสิทธิ์ปกติ |
| `notes` | บันทึกรุ่นที่แสดงในโปรแกรม — คั่นหัวข้อด้วย ` · ` (ใช้แยกเป็นรายการใน CHANGELOG ด้วย) |

### สิทธิ์อัปเดต (ตั้งแต่ v3.1.0)

- **Super Admin** อัปเดตได้เสมอ
- สมาชิกอัปเดตได้เมื่อ Super Admin **เปิดสิทธิ์ "อัปเดตโปรแกรม"** ให้ในหน้า *สมาชิก & ทีม* (ปุ่มสลับในแถวของแต่ละคน)
  สมาชิกที่ไม่มีสิทธิ์จะ *ไม่เห็นแจ้งเตือน* รุ่นใหม่เลย
- รุ่นที่ manifest ประกาศ `"open": true` ข้ามกติกาข้อบนรอบเดียว
- ระบบ KEY (v2.8.0–v3.0.0) ถูกยกเลิกแล้ว — `tools/keygen.py` ถูกลบออกจากรีโป (ดูได้ในประวัติ git ถ้าจำเป็น)

> เพราะแต่ละเครื่องมีฐานข้อมูลของตัวเอง สิทธิ์อัปเดตจึงเป็นเรื่องของเครื่องนั้น ๆ
> การประสานงาน "ทุกเครื่อง" ทำได้ทางเดียวคือ `open` ใน manifest

### ลืมรหัสผ่าน — สมาชิก (ตั้งแต่ v3.6.4)

สมาชิกกด **ลืมรหัสผ่าน?** ใต้หน้าเข้าสู่ระบบ แล้วยืนยันตัวตนด้วย **ชื่อที่ใช้เข้าเว็บ CRIMES** — ต้องตรงกับชื่อบัญชีที่โปรแกรม
**อ่านจากหน้าเว็บ CRIMES** ตอนคนนั้นเข้าระบบค้น (ตาราง `crimes_accounts` · ไม่สนตัวพิมพ์ใหญ่-เล็ก/ช่องว่างหัวท้าย) จึงตั้งรหัสผ่านใหม่
และเข้าสู่ระบบได้ทันที · ค่าที่ผู้ใช้กรอกเองในช่อง "บัญชี CRIMES ผู้ค้น" *ไม่นับ* (ไม่งั้นคนที่ยังเข้าถึงบัญชีได้จะฝังคำตอบไว้กู้บัญชีคืนได้)

- ใช้ได้เฉพาะบัญชีบทบาท *สมาชิก* ที่ยังเปิดใช้งาน และเรียกจากเครื่องที่ติดตั้งเท่านั้น (loopback) · คำตอบเมื่อไม่ผ่านเป็นข้อความกลาง ๆ
- สมาชิกที่ยังไม่เคยเข้าระบบค้นด้วยรุ่นนี้ (ยังไม่มีชื่อ CRIMES ที่ตรวจพบ) ต้องให้ Super Admin ตั้งรหัสใหม่ให้ในหน้าสมาชิก
- กรอกผิดหลายครั้งถูกหน่วงเหมือนล็อกอิน · PASSCODE ของบัญชีถูกยกเลิกเมื่อตั้งรหัสใหม่ · มีรายการในบันทึกการตรวจสอบ
- ตั้งรหัสใหม่ทางไหนก็ตาม (ลืมรหัส · ผู้ดูแลตั้งให้ · เปลี่ยนเอง) **session อื่นทั้งหมดของบัญชีนั้นหลุดทันที** (คงผลข้ามการรีสตาร์ท)
- **Super Admin ไม่มีทางกู้รหัสด้วยตัวเอง** (วิธีวางไฟล์ของ v3.6.3 ถูกยกเลิกตามคำขอ) — ต้องมี Super Admin อีกคนตั้งให้

ข้อควรรู้: ถ้ามีใครตั้ง PASSCODE ไว้ หน้าเข้าสู่ระบบจะเปิดช่อง PASSCODE ก่อน — รหัสผ่านต้องกด **🔑 รหัสผ่าน** ด้านบนก่อน

## ปล่อยรุ่นใหม่

```bash
python tools/release.py extract                 # ครั้งแรก: แตก zip รุ่นล่าสุดลง build/
#   … แก้โค้ดใน build/CRIMES_AUTO_update/app/ …
python tests/run_all.py                         # ต้องผ่านทั้งหมด (ต้องมี Chromium: python -m playwright install chromium)
python tools/release.py build --version 3.6.0 \
    --notes "เวอร์ชัน 3.6.0 — หัวข้อแรก · หัวข้อสอง"   # [--open] ถ้าต้องการให้ทุกเครื่องอัปเดตได้
python tests/run_all.py --quick                 # ยืนยันสั้น ๆ หลังเลขรุ่นเปลี่ยน
git add -A && git commit && git push            # → เปิด PR → รอ CI เขียว → merge เข้า main
python tools/release.py verify                  # ดาวน์โหลดของจริงจาก GitHub มาตรวจ sha256
```

กติกาที่ `release.py build` บังคับ: สร้างจาก zip รุ่นก่อนแล้วแทนเฉพาะไฟล์ที่เปลี่ยน · รายการไฟล์ต้องเท่าเดิม
(ไฟล์ใหม่ต้องสั่ง `--allow-new-files` ซึ่งจะใส่ลง zip และตรวจเหมือนไฟล์อื่น · ไฟล์ที่เลิกใช้ตัดออกด้วย `--remove app/…`
และต้องใส่ชื่อไว้ใน `app/OBSOLETE.txt` ด้วย เพื่อให้ตัวอัปเดตลบออกจากเครื่องผู้ใช้) ·
ห้ามมีไฟล์จาก `tools/` หรือกุญแจใด ๆ · ทุก `.py` ต้อง compile ผ่าน · ฟังก์ชันแกนของหน้าแรกต้องอยู่ครบ
(กันเหตุ "อัปเดตแล้วเปิดมาเป็นหน้าดำ" ที่เคยเกิดใน v2.9.2) · เลขรุ่นต้องใหม่กว่าเดิม

`release.py verify` เทียบ manifest ออนไลน์กับในเครื่องทุกช่อง (version · url · sha256 · open) แล้วดาวน์โหลด zip
ที่ manifest **ออนไลน์** ชี้มาตรวจ sha256 — ผ่านก็ต่อเมื่อผู้ใช้ปลายทางจะได้รับของตรงกับที่ปล่อยจริงเท่านั้น

ข้อควรรู้: หลัง merge แล้ว URL `raw.githubusercontent.com` อาจยังส่งค่า manifest เก่าอยู่ **ราว 5 นาที** (แคช CDN)
ถ้ากด "ตรวจสอบอัปเดต" แล้วยังไม่เห็นรุ่นใหม่ ให้รอสักครู่ · ตรวจของจริงบน `main` ด้วย `release.py verify`

## ชุดติดตั้งตัวเต็ม (ตั้งแต่ v3.8.0)

ชุดอัปเดต (zip ด้านบน) มีแค่โค้ดโปรแกรม — เครื่องใหม่ต้องมี Python runtime และ Chromium อยู่ก่อน
`tools/build_installer.py` สร้าง **ชุดติดตั้งตัวเต็ม** ที่มีครบทุกอย่างในคำสั่งเดียว (ไม่ต้องมีเครื่อง Windows ตอนสร้าง):

```bash
pip install playwright==<รุ่นใน tools/installer/versions.json>
CRIMES_INSTALL_PASSWORD='…' CRIMES_SEED_PASSWORD='…' python tools/build_installer.py
#   → dist/CRIMES_AUTO_Setup_v<ver>/ + .zip (+ .sha256)   · dist/ ไม่ขึ้น git
```

- **ในชุด**: `app/` (โปรแกรมรุ่นล่าสุดตาม manifest · ตัดไฟล์ใน `app/OBSOLETE.txt` และแคชออก) · `runtime/` (Python embeddable + wheels
  ทั้งหมดสำหรับ win_amd64) · `browsers/` (Chromium ที่ Playwright รุ่นเดียวกับใน runtime ดาวน์โหลดเอง) · `Install.ps1` + `ติดตั้ง.bat` ·
  `Uninstall.ps1` + `ถอนการติดตั้ง.bat` · `icon.ico` · `install.json` · `seed_account.json` · `README-ติดตั้ง.txt`
- **สองรหัสตอนสร้าง** ให้ทาง environment variable (หรือพิมพ์ตอนถาม) เท่านั้น — ไม่มีที่ไหนในรีโป/ชุดติดตั้งที่เก็บรหัสจริง:
  `CRIMES_INSTALL_PASSWORD` = รหัสเริ่มติดตั้ง → แฮช PBKDF2-SHA256 ใน `install.json` (Install.ps1 ตรวจ ผิด 3 ครั้งเลิก) ·
  `CRIMES_SEED_PASSWORD` = รหัสผ่านบัญชี Super Admin เริ่มต้น (`Superadmin`) → แฮชแบบเดียวกับโปรแกรมใน `seed_account.json`
  ด่านตรวจท้ายสุดกวาดทุกไฟล์ในชุดเพื่อยืนยันว่าไม่มีรหัสเป็นข้อความธรรมดา
- **ติดตั้ง**: แตก zip → `ติดตั้ง.bat` → ใส่รหัสเริ่มติดตั้ง → ลง `%LOCALAPPDATA%\CRIMES-AUTO` (ไม่ต้องใช้สิทธิ์ผู้ดูแลเครื่อง)
  เครื่องที่มีอยู่แล้ว = อัปเกรด เก็บ `data/` `uploads/` เดิม สำรอง `data.db` ก่อน ลบไฟล์ที่เลิกใช้ ·
  สร้างทางลัดเดสก์ท็อป/Start Menu + รายการใน Settings → Apps · ติดตั้งหลายเครื่องแบบไม่ถาม: `Install.ps1 -Password … -Silent`
- **บัญชีเริ่มต้น**: เครื่องใหม่ (ยังไม่มี `data.db`) ได้ `seed_account.json` วางไว้ข้าง `db.py` → เปิดครั้งแรกโปรแกรมสร้าง Super Admin จากไฟล์
  แล้วลบไฟล์ทิ้งทันที (มีผู้ใช้อยู่แล้ว/ไฟล์เสียก็ลบ) · `/api/me` บอก `seed_password` และหน้าจอขึ้นป้ายเตือน "เปลี่ยนรหัสผ่านเดี๋ยวนี้"
  ทุกครั้งที่เข้า จนกว่าจะเปลี่ยน (ทางไหนก็ได้ — ป้ายเทียบแฮชกับที่จดใน `meta`)
- **ถอนการติดตั้ง** (Start Menu / Settings → Apps / `ถอนการติดตั้ง.bat`): ปิดโปรเซส → ถามยืนยัน `YES` → เสนอสำรองข้อมูลไว้ที่เดสก์ท็อป →
  ลบโฟลเดอร์ติดตั้งทั้งหมด (รวมฐานข้อมูล) · ทางลัด · คีย์รีจิสทรี `HKCU\…\Uninstall\CRIMES-AUTO` · `~\.crimes_auto_profile` ·
  `%TEMP%\crimes_upd_*` · แคช WebView2 (`%LOCALAPPDATA%\pywebview`) · การติดตั้งแบบเก่าที่ `C:\Crimes-Automate` (ถ้าพบและยืนยัน)
- **สร้างอัตโนมัติบน GitHub**: workflow `installer` (Actions → Run workflow) บน `windows-latest` ใช้ secrets
  `INSTALLER_GATE_PASSWORD` / `INSTALLER_SEED_PASSWORD` แล้วอัปโหลด zip เป็น artifact (7 วัน)
  ⚠ รีโปนี้เป็นสาธารณะ — ใครที่ล็อกอิน GitHub ก็ดาวน์โหลด artifact ได้ และแฮชของรหัสสั้น ๆ เดาออฟไลน์ได้
  ทางที่ปิดกว่าคือรันคำสั่งข้างบนบนเครื่องผู้ดูแลเอง แล้วส่งชุดให้เครื่องปลายทางตรง ๆ
- รุ่น Python/Playwright/ชื่อบัญชีเริ่มต้น/รอบแฮชของรหัสเริ่มติดตั้ง อยู่ใน `tools/installer/versions.json` ·
  ทดสอบตัวสร้างด้วย `tests/test_installer.py` (จำลองการดาวน์โหลดทั้งหมด) · ตัวโปรแกรมด้วย `tests/test_v380.py`

## ทดสอบ

```bash
pip install flask waitress openpyxl playwright && python -m playwright install chromium
python tests/run_all.py            # ทั้งหมด ~10 นาที
python tests/run_all.py --quick    # เฉพาะชุดที่ไม่เปิดเบราว์เซอร์ ~1 นาที
python tests/run_all.py --only e2e # ไฟล์เดียว
```

ทุกชุดทดสอบกับ **ไบต์ในแพ็กเกจรุ่นล่าสุด** (แตกลง `build/` ให้เองครั้งแรก) ไม่ใช่โค้ดลอย ๆ
ตั้ง `CRIMES_APP_DIR=/path/to/app` ถ้าต้องการชี้ไปที่ทรีอื่น

| ชุด | ครอบคลุม |
|---|---|
| `test_v2100` … `test_v370` | กติกาของแต่ละรุ่น (API · ฐานข้อมูล · ตัวอ่านเลขบัตร · สี/มาร์คในไฟล์ · คิว · สิทธิ์ · คอลัมน์ผล F · นับถอยหลังเริ่มเอง · ลืมรหัสผ่านสมาชิก · ไดเรกทอรีสมาชิกกลาง 2 เครื่องผ่านสคริปต์ศูนย์กลางตัวจริงบน Node) |

## ไดเรกทอรีสมาชิกกลาง (ตั้งแต่ v3.7.0)

ทุกเครื่องที่เชื่อมศูนย์กลางใช้ **สมาชิกชุดเดียวกัน**: สร้าง/แก้/ปิดใช้งาน/ตั้งรหัสใหม่ที่เครื่องไหน ก็ใช้เข้าได้ทุกเครื่อง

- โปรแกรมส่ง *เฉพาะสมาชิกที่เครื่องนี้แก้* ขึ้นศูนย์กลางและรับของทั้งองค์กรกลับมาในคำขอเดียว (`kind="members"`) — คีย์คือชื่อผู้ใช้
  **ศูนย์กลางเป็นผู้ตัดสิน** ด้วยเลขรุ่น `rev` ต่อแถว (ไม่ใช้นาฬิกาของเครื่องใด): แถวที่ส่งต้องอ้าง rev ที่เห็นล่าสุด ไม่ตรง = มีคนแก้ก่อน → ของกลางชนะ
  และเครื่องนั้นได้ของกลางกลับไปทับ (แถบสถานะบอก "ถูกของกลางทับ") · คนที่ถูกลบมีป้ายหลุมศพ (`member_tombstones`) → เครื่องอื่น *ปิดใช้งาน* ตาม (ไม่ลบ กันประวัติกำพร้า)
- **สองรหัส** (ดู `tools/README.md`): รหัสลับ `HUB_TOKEN` อยู่ในรหัสเชื่อมต่อที่แจกทุกเครื่อง — ใช้ดึงไดเรกทอรีและส่ง *รหัสผ่านใหม่ของสมาชิกธรรมดา* (เปลี่ยนรหัสตัวเอง/ลืมรหัส) ได้เท่านั้น
  **รหัสผู้ดูแลศูนย์กลาง `ADMIN_TOKEN`** ใส่เฉพาะเครื่องของ Super Admin (ตอนสมัครเครื่องแรก หรือ Setting → ศูนย์กลาง) — จำเป็นสำหรับสร้างคน · แก้บทบาท/สิทธิ์/สถานะ/ชื่อ/อัตรา · ลบ · แตะบัญชี Super Admin
  เครื่องที่ไม่มีรหัสนี้แก้ในเครื่องได้ตามสิทธิ์เดิม แต่รายการจะ **ค้างส่ง** (แถบสถานะบอกจำนวนและเหตุผล) จนกว่าจะใส่รหัสผู้ดูแลในเครื่องนั้น
  ⇒ คนในที่อ่าน config.json ของเครื่องสมาชิกได้ จะเอารหัสร่วมไปตั้งตัวเองเป็น Super Admin หรือเปลี่ยนรหัสผ่านคนอื่นผ่านศูนย์กลางไม่ได้
- ศูนย์กลาง **ไม่รับการแก้ที่ทำให้ไม่เหลือ Super Admin ที่เปิดใช้งาน** (สองเครื่องปิดกันเองพร้อมกัน → คนหลังถูกปัดตก) และเครื่องแต่ละเครื่องก็ไม่ลดขั้น Super Admin คนสุดท้ายของตนตามไดเรกทอรีที่ไม่มีคนอื่น
- ซิงก์เมื่อ: เชื่อมต่อ · ตั้งค่าเครื่อง · ทุกรอบตัวจับเวลา · หลังแก้สมาชิก/รหัสผ่าน · ใส่รหัสผู้ดูแล · ล็อกอินไม่ผ่าน (บัญชีอาจเพิ่งถูกสร้างที่เครื่องอื่น) · ปุ่ม "🔄 ซิงก์เดี๋ยวนี้" บนหน้าสมาชิก
- รหัสผ่านถูกเปลี่ยนจากเครื่องอื่น → เครื่องนี้ตัด session เดิมของคนนั้นและยกเลิก PASSCODE ของเขาบนเครื่องนี้
- **เครื่องใหม่**: หน้าตั้งค่าเลือก "🔗 เครื่องเพิ่มเติม" วางรหัสเชื่อมต่อ → ดึงสมาชิกมาแล้วเข้าด้วยบัญชีเดิม (ไม่สร้าง Super Admin ซ้ำ)
  "🏠 เครื่องแรกขององค์กร" สร้าง Super Admin ตามเดิม (วางรหัสเชื่อมต่อ + รหัสผู้ดูแลด้วยได้ → บัญชีนั้นขึ้นไดเรกทอรีกลางทันที · ไดเรกทอรีว่างรับได้โดยไม่ต้องมีรหัสผู้ดูแล)
- ศูนย์กลางต้องใช้ `tools/hub_gas.js` รุ่น v3.7.0 (ชีต `members` + ตั้ง `ADMIN_TOKEN`) — วางทับแล้ว **Deploy → Manage deployments → New version**
  โปรแกรมรุ่นใหม่ที่คุยกับสคริปต์รุ่นเก่าจะขึ้น "ศูนย์กลางรุ่นเก่า ยังไม่รองรับไดเรกทอรีสมาชิก" (ตัวเลข/สถานะยังส่งได้ตามเดิม) · ยังไม่ตั้ง `ADMIN_TOKEN` → โปรแกรมบอกให้ตั้ง
- ชีต `members` มีแฮชรหัสผ่าน (pbkdf2 200,000 รอบ + salt รายคน — ไม่ใช่รหัสผ่านจริง แต่เดาออฟไลน์ได้ถ้าหลุด) **แชร์ไฟล์ Sheet ให้เฉพาะผู้ดูแล**
- ไม่ซิงก์: PASSCODE (ผูก secret ของเครื่อง) · ทีม · ประวัติการค้น · เวลาเห็นล่าสุด (ไปทาง presence อยู่แล้ว)
- ชุดทดสอบรันสคริปต์ศูนย์กลางตัวจริงด้วย Node (`tests/gas_harness.js` จำลอง SpreadsheetApp) จำลอง 2 เครื่องซิงก์ผ่าน Sheet เดียวกัน

## นโยบายข้อมูล (ศูนย์กลาง)

โปรแกรมส่งขึ้นศูนย์กลาง (Google Apps Script — ถ้าผู้ดูแลเปิดใช้):
- **ตัวเลขนับ**: จำนวนการค้นรายวันรายคน (รวม/พบ/ไม่พบ/ผิดพลาด) · จำนวนไฟล์ · ยอดรับ/จ่าย · ชื่อที่แสดง · รหัสเครื่อง · เวอร์ชัน · เวลาที่เห็นล่าสุด
- **ไดเรกทอรีสมาชิก (v3.7.0 — เจ้าของโปรเจกต์อนุมัติ)**: ชื่อผู้ใช้ล็อกอิน · ชื่อที่แสดง · บทบาท · สิทธิ์ · สถานะ · รหัสผ่านแบบแฮช+salt · อัตราค่าบริการ · เวลาสร้าง/แก้ · เลขรุ่น (`rev`) ที่ศูนย์กลางกำหนด

**ไม่ส่งออกจากเครื่องเด็ดขาด:** เลขบัตรประชาชน · ชื่อผู้ถูกค้น · ผลคดี/รายละเอียดคดี · ชื่อไฟล์งาน · รหัสผ่านตัวจริง · PASSCODE · KEY

การเปลี่ยนแปลงใดที่เพิ่มฟิลด์ที่ส่งขึ้นศูนย์กลาง ต้องตรวจกับรายการนี้ก่อนเสมอ (ดู `backend/hub.py` — ALLOWED_FIELDS / PRESENCE_FIELDS / MEMBER_FIELDS)
