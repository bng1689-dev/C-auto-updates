CRIMES AUTO — ชุดติดตั้งตัวเต็ม
==================================

ชุดนี้มีทุกอย่างที่ต้องใช้แล้ว (Python runtime · Chromium · โปรแกรมรุ่นล่าสุด) ติดตั้งได้โดยไม่ต้องต่ออินเทอร์เน็ต
และไม่ต้องใช้สิทธิ์ผู้ดูแลเครื่อง (ติดตั้งลง %LOCALAPPDATA%\CRIMES-AUTO ของผู้ใช้ที่ล็อกอิน Windows อยู่)

วิธีติดตั้ง
-----------
1. แตก zip ทั้งหมดลงโฟลเดอร์ใดก็ได้ (ต้องแตกให้ครบก่อน อย่ารันจากในหน้าต่าง zip)
2. ดับเบิลคลิก  ติดตั้ง.bat  (หรือ Install.bat)
3. ใส่ "รหัสเริ่มติดตั้ง" ที่ได้รับจากผู้ดูแลโครงการ (ถามผู้ดูแล — ไม่ได้เขียนไว้ในชุดนี้)
4. รอจนขึ้น [OK] โปรแกรมจะเปิดขึ้นเอง และมีทางลัด "CRIMES AUTO" บนเดสก์ท็อป/Start Menu

เข้าใช้งานครั้งแรก (เครื่องใหม่ที่ยังไม่มีข้อมูล)
--------------------------------------------------
- เครื่องเพิ่มเติมขององค์กรที่ใช้ศูนย์กลางอยู่แล้ว (ตั้งแต่ v3.10.0): กด "สมัครใช้งาน" ที่หน้าเข้าสู่ระบบ
  แล้วรอ Super Admin อนุมัติ — หรือเข้าด้วยบัญชีเดิมของคุณได้เลย (โปรแกรมดึงสมาชิกจากศูนย์กลางเอง)
  เครื่องแบบนี้จะไม่สร้างบัญชี Superadmin เริ่มต้นให้ (กันบัญชีผู้ดูแลซ้ำซ้อนทุกเครื่อง)
- เครื่องแรกขององค์กร (ศูนย์กลางยังว่าง/ไม่ได้ใช้ศูนย์กลาง): มีบัญชี Super Admin เริ่มต้นชื่อ  Superadmin
  เตรียมไว้แล้ว (รหัสผ่านถามผู้ดูแลโครงการ)
- เข้าครั้งแรกด้วยบัญชีเริ่มต้นแล้วโปรแกรมจะเตือนให้ "เปลี่ยนรหัสผ่าน" — ทำทันทีที่ Setting → เปลี่ยนรหัสผ่าน
  (ป้ายเตือนหายเองเมื่อรหัสถูกเปลี่ยน)
- เครื่องที่ติดตั้งโปรแกรมอยู่แล้ว: ชุดนี้จะอัปเกรดให้เป็นรุ่นล่าสุด บัญชี/ประวัติ/การตั้งค่าเดิมอยู่ครบ
  ไฟล์ของรุ่นเก่าที่เลิกใช้แล้วถูกลบออกให้ และไม่มีการสร้างบัญชีเริ่มต้นซ้ำ

ติดตั้งหลายเครื่องแบบไม่ต้องกดอะไร
-----------------------------------
    powershell -NoProfile -ExecutionPolicy Bypass -File Install.ps1 -Password <รหัสเริ่มติดตั้ง> -Silent

ถอนการติดตั้ง (ลบทั้งหมด)
-------------------------
- Start Menu → CRIMES AUTO → "ถอนการติดตั้ง CRIMES AUTO"  หรือ  Settings → Apps → CRIMES AUTO → Uninstall
- หรือดับเบิลคลิก  ถอนการติดตั้ง.bat  ในโฟลเดอร์ติดตั้ง (%LOCALAPPDATA%\CRIMES-AUTO)
- จะลบโปรแกรม runtime Chromium ฐานข้อมูล บัญชี ประวัติ ไฟล์อัปโหลด ทางลัด รายการใน Add/Remove Programs
  โปรไฟล์ Chrome ของโปรแกรม และไฟล์ชั่วคราว — ก่อนลบจะถามว่าจะสำรองข้อมูลไว้ที่เดสก์ท็อปไหม

สิทธิ์อัปเดต
------------
บัญชี Super Admin อัปเดตโปรแกรมออนไลน์ได้ทันที (Setting → อัปเดต) และเป็นผู้ให้สิทธิ์ "อัปเดตโปรแกรม" แก่สมาชิกคนอื่น
ไม่ต้องใช้ KEY ใด ๆ อีกต่อไป (ระบบ KEY ถูกยกเลิกตั้งแต่ v3.1.0)

ความปลอดภัย
-----------
ในชุดติดตั้งไม่มีรหัสเริ่มติดตั้งและรหัสผ่านบัญชีเริ่มต้นอยู่ที่ไหนเลย — มีแต่ค่าแฮช (install.json / seed_account.json)
ไฟล์ seed_account.json ถูกใช้แล้วลบทันทีตอนเปิดโปรแกรมครั้งแรก · อย่าส่งชุดติดตั้งนี้ให้บุคคลภายนอก
ข้อยกเว้นเดียว: รหัสลับศูนย์กลาง (HUB_TOKEN) ฝังมากับโปรแกรม (และอาจมี hub_seed.json ถ้าผู้สร้างชุดกำหนดรหัสอื่น)
— รหัสนี้ใช้แค่ยืนยันว่า "เครื่องขององค์กร" ตอนคุยกับศูนย์กลาง ไม่ใช่รหัสผ่านของใคร · รหัสผู้ดูแลศูนย์กลาง (ADMIN_TOKEN) ไม่อยู่ในชุดนี้
