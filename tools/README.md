# เครื่องมือผู้ดูแลระบบ (ห้ามแจกไปกับโปรแกรม)

ไฟล์ในโฟลเดอร์นี้ **ไม่ถูกรวมในชุดอัปเดต** ที่ส่งให้ผู้ใช้ และต้องไม่ถูกรวมเด็ดขาด

## keygen.py — ออก KEY อนุญาตอัปเดต

    python tools/keygen.py init              # สร้างกุญแจครั้งแรก (ทำครั้งเดียว)
    python tools/keygen.py issue --user ชื่อผู้ใช้
    python tools/keygen.py check --key "v1.xxx.yyy"

`init` จะสร้างไฟล์ **`crimes_license_private.json`** = กุญแจลับ
เก็บเป็นความลับ ห้าม commit ขึ้น git ห้ามส่งต่อ — ถ้าหลุด ใครก็ออก KEY เองได้

จากนั้นนำ "กุญแจสาธารณะ" ที่พิมพ์ออกมา ไปวางในโปรแกรมที่
**Setting → KEY อนุญาตอัปเดต → กุญแจสาธารณะ** แล้วกดบันทึก
ระบบ KEY จะเริ่มบังคับใช้ทันทีหลังตั้งกุญแจ

ผู้ขอ KEY ต้องแจ้ง **ชื่อผู้ใช้** และ **รหัสติดตั้ง** (ดูได้ในหน้าเดียวกันบนเครื่องของเขา)

## hub_gas.js — ศูนย์กลางรวมตัวเลข (Google Apps Script)

ใช้เมื่อมีหลายเครื่องและอยากดูยอดรวมที่เดียว **ส่งเฉพาะตัวเลขนับ** ขึ้นไป
ข้อมูลประวัติ เลขบัตร ผลคดี และชื่อไฟล์งาน **ไม่ออกจากเครื่อง**

ติดตั้ง:

1. สร้าง Google Sheet ใหม่ → เมนู **Extensions → Apps Script** → วางโค้ดจาก `hub_gas.js`
2. แก้ `HUB_TOKEN` เป็นรหัสลับของคุณเอง (สุ่มยาว ≥ 32 ตัว)
3. **Deploy → New deployment → Web app** · Execute as: **Me** · Who has access: **Anyone**
4. คัดลอก URL ที่ลงท้าย `/exec` ไปใส่ในโปรแกรมทุกเครื่องที่
   **Setting → ศูนย์กลางรวมตัวเลข** พร้อมรหัสลับเดียวกัน แล้วติ๊กเปิดใช้งาน

ข้อควรรู้:

- ปลายทางคือ Google ซึ่งเป็นบริการภายนอกหน่วยงาน — เป็นการตัดสินใจเชิงนโยบาย
- ทุกเครื่องใช้รหัสลับเดียวกัน จึงกันคนนอกได้ แต่ไม่ได้กันคนในที่ตั้งใจส่งตัวเลขปลอมของตัวเอง
  ให้ดูคอลัมน์ `install_id` ในชีตประกอบเสมอ
- ส่งซ้ำเดือนเดิมจากเครื่องเดิมจะ **แทนที่** ของเก่า ไม่ใช่บวกเพิ่ม


## v3.2.0 — รหัสเชื่อมต่อศูนย์กลาง (เชื่อมสมาชิกใหม่ตั้งแต่สมัคร)

1. ผู้ดูแลตั้ง URL + รหัสลับของศูนย์กลางในเครื่องตัวเองตามเดิม (Setting → ศูนย์กลางรวมตัวเลข)
2. กด **📋 คัดลอกรหัสเชื่อมต่อ (แจกสมาชิก)** — ได้สตริง `CRIMES-HUB:...` (มีรหัสลับอยู่ข้างใน
   ส่งให้เฉพาะคนในหน่วยงาน ห้ามโพสต์สาธารณะ)
3. สมาชิกติดตั้งโปรแกรม แล้ววางรหัสนี้ที่ช่อง **"รหัสเชื่อมต่อศูนย์กลาง"** ตอนสมัครใช้งาน →
   เครื่องนั้นเชื่อมศูนย์กลางทันที (ส่งสถานะทันที + ตัวเลขทุก 1 นาที และทันทีเมื่อรอบค้นจบ/บันทึกรับ-จ่าย)
4. เครื่องที่ติดตั้งไปแล้ว: วางรหัสที่ Setting → ศูนย์กลาง → "🔗 เชื่อมต่อด้วยรหัส"
5. **ต้องวาง `hub_gas.js` รุ่นนี้ทับแล้ว Deploy ใหม่** (ชีต `presence` ใหม่ + ก้อน presence ไม่ลบตัวเลข)

หมายเหตุ: `keygen.py` และระบบ KEY ถูกยกเลิกตั้งแต่ v3.1.0 — ใช้สิทธิ์ "อัปเดตโปรแกรม" ในหน้าสมาชิกแทน
