(`release.py build` ตรวจและปฏิเสธถ้ามีไฟล์จากโฟลเดอร์นี้หลุดเข้าไปในแพ็กเกจ)

| `build_installer.py` | สร้าง **ชุดติดตั้งตัวเต็ม** (Python runtime + Chromium + โปรแกรมรุ่นล่าสุด + ตัวติดตั้ง/ถอน) ลง `dist/` — รหัสเริ่มติดตั้งและรหัสบัญชีเริ่มต้นให้ทาง env `CRIMES_INSTALL_PASSWORD` / `CRIMES_SEED_PASSWORD` เท่านั้น (เก็บเป็นแฮช) · รายละเอียดใน [README หลัก](../README.md#ชุดติดตั้งตัวเต็ม-ตั้งแต่-v380) |

## hub_gas.js — ศูนย์กลางรวมตัวเลข (Google Apps Script)

ใช้เมื่อมีหลายเครื่อง: รวมตัวเลขนับที่เดียว · ไดเรกทอรีสมาชิกชุดเดียวกัน (v3.7.0) · สมุดกองกลางเล่มเดียวกัน (v3.9.0)
ข้อมูลประวัติ เลขบัตร ผลคดี และชื่อไฟล์งาน **ไม่ออกจากเครื่อง** (รายการเต็มอยู่ใน README หลัก — หัวข้อ "นโยบายข้อมูล")

### ติดตั้งครั้งแรก

1. สร้าง Google Sheet ใหม่ → เมนู **Extensions → Apps Script** → วางโค้ดจาก `hub_gas.js`
2. แก้ `HUB_TOKEN` เป็นรหัสลับของคุณเอง (สุ่มยาว ≥ 32 ตัว) — ค่าในรีโปเป็นแค่ตัวยึดที่
   และแก้ `ADMIN_TOKEN` เป็นรหัสอีกชุด (ต่างจาก `HUB_TOKEN`, ≥ 8 ตัว) = **รหัสผู้ดูแลศูนย์กลาง** — ยังเป็นค่าตั้งต้น = ศูนย์กลางไม่รับการแก้ไดเรกทอรีสมาชิกจากเครื่องไหนเลย
3. **Deploy → New deployment → Web app** · Execute as: **Me** · Who has access: **Anyone**
4. คัดลอก URL ที่ลงท้าย `/exec` ไปใส่ในโปรแกรมของผู้ดูแลที่ **Setting → ศูนย์กลางรวมตัวเลข** พร้อมรหัสลับ แล้วกด **บันทึกและเชื่อมต่อ** (v3.9.0: เปิดใช้และซิงก์เองทันที ไม่มีติ๊กเปิดต่างหาก)
   ใส่ **🔑 รหัสผู้ดูแลศูนย์กลาง** (`ADMIN_TOKEN`) ในช่องถัดลงมา **เฉพาะเครื่องของ Super Admin** (หรือใส่ตั้งแต่ตอนสมัครเครื่องแรก)
5. กด **📋 คัดลอกรหัสเชื่อมต่อ (แจกสมาชิก)** — ได้สตริง `CRIMES-HUB:…` (มี `HUB_TOKEN` อยู่ข้างใน **ไม่มี** `ADMIN_TOKEN` · ส่งให้เฉพาะคนในหน่วยงาน ห้ามโพสต์สาธารณะ)
   - สมาชิกใหม่: วางรหัสนี้ที่ช่อง **"รหัสเชื่อมต่อศูนย์กลาง"** ตอนสมัครใช้งาน → เชื่อมทันที
   - เครื่องที่ติดตั้งแล้ว: Setting → ศูนย์กลาง → **🔗 เชื่อมต่อด้วยรหัส**

สิทธิ์ตามรหัสที่เครื่องมี:

| เครื่องมี | ทำได้ผ่านศูนย์กลาง |
|---|---|
| `HUB_TOKEN` (ทุกเครื่อง) | ส่งตัวเลข/สถานะ · ดึงไดเรกทอรีสมาชิก · ส่ง *รหัสผ่านใหม่ของสมาชิกธรรมดาที่มีอยู่แล้ว* (เปลี่ยนรหัสตัวเอง/ลืมรหัส) · **ดึง**สมุดกองกลางและทีม (v3.9.1: โปรแกรมไม่ให้จัดทีม/บันทึกกองกลางบนเครื่องแบบนี้เลย — ดูอย่างเดียว) |
| + `ADMIN_TOKEN` (เครื่อง Super Admin) | สร้างคน · แก้บทบาท/สิทธิ์/สถานะ/ชื่อ/อัตรา · ลบ · ตั้งรหัสให้คนอื่น/Super Admin · **จัดทีม (ชื่อ/อัตราทีม/สมาชิกในทีม)** และ **บันทึก/ลบรายการกองกลาง** (v3.9.0) |

ศูนย์กลางตัดสินลำดับการแก้ด้วยเลขรุ่น `rev` ของตัวเอง (ไม่ใช้นาฬิกาเครื่อง) และไม่รับการแก้ที่ทำให้ไม่เหลือ Super Admin ที่เปิดใช้งาน
รายการที่ถูกปัดตกจะขึ้นบนแถบสถานะหน้าสมาชิกของเครื่องนั้น ("รอส่ง N" พร้อมเหตุผล / "ถูกของกลางทับ")

### อัปเดตสคริปต์เมื่อมีรุ่นใหม่ของ `hub_gas.js`

วางโค้ดใหม่ทับใน Apps Script แล้ว **Deploy → Manage deployments → กดดินสอ ✏ ที่อันเดิม → Version: New version → Deploy**

⚠ **ห้ามกด "New deployment"** — จะได้ URL `/exec` ใหม่ ทำให้ทุกเครื่องที่ตั้งค่าไว้แล้วยังส่งเข้าสคริปต์ตัวเก่า
และข้อมูลไม่เข้าโดยไม่มีใครรู้

รุ่นที่ต้องอัปเดตสคริปต์: **v3.2.0 ขึ้นไป** (ชีต `presence` · ก้อน presence ไม่ลบตัวเลขรายเดือน · ล็อกกันเขียนชนกัน · กันสูตรฝังในเซลล์)
และ **v3.7.0 ขึ้นไป** (ชีต `members` — ไดเรกทอรีสมาชิกกลาง: โปรแกรมส่งสมาชิกที่แต่ละเครื่องแก้มาเก็บ ศูนย์กลางตัดสินด้วย `rev` แล้วส่งของทั้งองค์กรกลับไป
· ต้องตั้ง `ADMIN_TOKEN` · สคริปต์รุ่นเก่าจะทำให้โปรแกรมแจ้ง "ศูนย์กลางรุ่นเก่า ยังไม่รองรับไดเรกทอรีสมาชิก" · ชีตนี้มีแฮชรหัสผ่าน — แชร์ไฟล์ Sheet ให้เฉพาะผู้ดูแล)
และ **v3.9.0 ขึ้นไป** (ชีต `ledger` — สมุดกองกลางกลาง: ทุกเครื่องเห็นรายการรับ/จ่ายชุดเดียวกัน · การเพิ่ม/ลบต้องเซ็นด้วย `ADMIN_TOKEN` · ตอบส่วนต่างตั้งแต่ `after`
· ชีต `members` เพิ่มคอลัมน์ `teams` (ทีมที่สังกัด — สคริปต์เติมหัวคอลัมน์ให้ชีตรุ่น 3.7.0 เอง) · กระดาน `doGet` คิดยอดเงินจากชีต `ledger`
และ **v3.9.2 ขึ้นไป** (สคริปต์ตอบ `ver` = `HUB_SCRIPT_VERSION` ทุกคำตอบ → โปรแกรมโชว์ "🧩 สคริปต์ศูนย์กลาง: รุ่น …" ในหน้าตั้งค่า ใช้ยืนยันว่า Deploy รุ่นใหม่มีผลแล้ว)

**วางทับให้ถูกวิธี**: ใน Apps Script เลือกโค้ดเดิมทั้งหมด → ลบ → วางไฟล์ใหม่ทั้งไฟล์ (ห้ามวางต่อท้าย — ถ้าโค้ดเก่าอยู่ท้ายไฟล์ `doPost` เดิมจะชนะ) → ใส่ `HUB_TOKEN`/`ADMIN_TOKEN` เดิมกลับ → บันทึก → **Deploy → Manage deployments → ✏ → Version: New version → Deploy** · ถ้าหน้าตั้งค่ายังขึ้น "รุ่นเก่า" แปลว่ายังไม่ได้กด New version หรือ URL ในโปรแกรมชี้ไป deployment อื่น
· สคริปต์รุ่นเก่าจะทำให้โปรแกรมแจ้ง "ศูนย์กลางรุ่นเก่า ยังไม่รองรับสมุดกองกลางกลาง" — ตัวเลข/สมาชิกยังซิงก์ได้ตามเดิม)
ทดสอบสคริปต์ตัวจริงนอก Google ได้ด้วย `tests/gas_harness.js` (Node จำลอง SpreadsheetApp) — ชุดทดสอบ `tests/test_v370.py` ใช้ตัวนี้จำลอง 2 เครื่อง

### ข้อควรรู้

- ปลายทางคือ Google ซึ่งเป็นบริการภายนอกหน่วยงาน — เป็นการตัดสินใจเชิงนโยบาย ค่าเริ่มต้นของโปรแกรมคือ *ปิด*
- ทุกเครื่องใช้รหัสลับเดียวกัน จึงกันคนนอกได้ แต่ไม่ได้กันคนในที่ตั้งใจส่งตัวเลขปลอมของตัวเอง
  ให้ดูคอลัมน์ `install_id` ในชีตประกอบเสมอ
- ส่งซ้ำเดือนเดิมจากเครื่องเดิมจะ **แทนที่** ของเก่า ไม่ใช่บวกเพิ่ม · ก้อน presence แทนที่ทั้งชุดของเครื่องนั้น (สมาชิกที่ถูกลบจะหายจากชีต)
- โปรแกรมส่งทันทีเมื่อล็อกอิน/รอบค้นจบ/บันทึกรับ-จ่าย และตามรอบเวลา (ค่าเริ่มต้น 1 นาที)
